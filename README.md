# Mano liniuotė

Paprasta React + Vite programa, kurioje galima pasirinkti liniuotės ilgį nuo 0 iki 20 cm.

## Paleidimas

Reikalingas įdiegtas Node.js ir npm.

```bash
npm install
npm run dev
```

Terminale Vite parodys adresą. Atidaryk jį naršyklėje.

## Duomenys

Pasirinktas ilgis saugomas naršyklės `localStorage` raktu `ruler-measurement`. Jis išlieka tame pačiame įrenginyje ir naršyklėje. `localStorage` duomenys nėra siunčiami į GitHub ir nėra bendrinami su kolega.

## Dalijimasis per GitHub

Įkelk šį projekto aplanką į GitHub repozitoriją. Kolega gali parsisiųsti repozitoriją, atsidaryti terminalą jos aplanke ir paleisti `npm install`, tada `npm run dev`.

Projektas JavaScript pagrindu, be backend paslaugų, Supabase, Zapier, Vercel, TypeScript ar papildomų UI bibliotekų. Darbo eiga nenaudoja Issues, papildomų šakų ar pull request.
